ship_demo 的这套流程只在 ISDD 上可用（F1=0.635），在其余三个数据集上 F1 都不超过 0.15。整理结果已写入 README 第 7.0 节，数字都用记录的 TP/FP/FN 重新算过，GT 总数也对得上。

### 四个数据集的统一对照

口径统一为类别无关匹配（预测框与标注框 IoU≥0.3 即命中，不看舰种），默认配置为 FP32、切图、conf=0.35。

| 数据集             | 场景                       | 规模               | P / R / F1                | 其他配置                                |
| ------------------ | -------------------------- | ------------------ | ------------------------- | --------------------------------------- |
| ISDD               | 卫星热红外，目标约 20×10px | 1284 图 / 3061 框  | 0.709 / 0.575 / **0.635** | 不切图 F1 0.239；INT8 F1 0.591          |
| infrared-boat      | 近岸民用小艇               | 131 图 / 309 框    | 0.105 / 0.117 / **0.111** | 未做其他配置                            |
| Naval Warship OBB† | 可见光/卫星/无人机         | 822 图 / 2385 框   | 0.116 / 0.034 / **0.053** | IoU 放宽到 0.1：F1 0.147                |
| 睿创微纳           | 红外，混合分辨率           | 8402 图 / 26445 框 | 0.191 / 0.060 / **0.091** | 不切图 F1 0.039；调参后最好 0.093~0.130 |

Naval Warship 那次运行的完整命令当时没有贴出，我按推荐配置记录。睿创微纳这一行是由切图 + 只看军舰的日志换算的，与全类口径等价。

### 主要结论

1. **切图普遍有收益。** ISDD 上召回提高 4.1 倍、F1 提高 2.7 倍。睿创微纳整体召回提高 2.9 倍，其中 1280x1024 达 5.4 倍。但收益补不了域差异，睿创微纳切图后仍只有 F1≈0.09~0.13。
2. **“红外还是可见光决定边界”的猜想被证伪。** 睿创微纳是红外加军舰、类别对口，照样失败。目前唯一有效的只有 ISDD，具体决定因素还没查清。
3. **舰种和军民区分没有证据。** 睿创微纳上军舰命中率 2.2%、民用船 2.1%，几乎一样，命中军舰的框里 82~86% 判成 destroyer。ISDD 和 infrared-boat 的标注没有舰种，无法检验。Naval Warship 我们只做了类别无关评估，舰种分类准确率从未被检验过。
4. **INT8 的代价和约束。** F1 相对下降 6.9%，体积压到 46%，检测头必须保持 FP32，否则输出全零。CPU 上 INT8 不一定更快，早期版本实测反而更慢，最终版的速度还没测。

### 可信度提醒

- **0.635 略偏乐观**：ISDD 的 conf=0.35 是在评估集本身上扫出来的。睿创微纳的“调参后最好”同样是在评估子集上挑的，但即便如此仍然很低。
- **规模差异大**：infrared-boat 只有 131 张，结论较粗。睿创微纳用的是 train 集，且混有多种分辨率。
- **训练数据不明**：shipdata.yaml 的内容未知，无法排除模型与 ISDD 有来源上的关联。
