##  深层网络 vs 高分辨率特征图
---

| 网络深度角度 |            语义抽象角度            |     特征图分辨率角度     | 典型特征图 |
| :----------: | :--------------------------------: | :----------------------: | :--------: |
|   **浅层**   |  **低层特征**（边缘、纹理、颜色）  | **高分辨率层**（H×W 大） |   C2、C3   |
|   **深层**   | **高层特征**（物体部件、整体语义） | **低分辨率层**（H×W 小） |   C4、C5   |

------

### **为什么会混淆？**

因为"高层"和"低层"这两个词在不同语境下指的东西不一样：

- **从语义抽象角度说**："高层特征"指的是语义信息丰富的特征（比如"这是一只猫"），它来自网络的**深层**；"低层特征"指的是基础视觉特征（比如"这是一条边"），它来自网络的**浅层**。

- **从特征金字塔的图示角度看**：FPN 的图通常画成一个倒金字塔，**上面**画的是深层（语义强、分辨率低），**下面**画的是浅层（细节多、分辨率高）。

所以图里的"上层"=深层=低分辨率，"下层"=浅层=高分辨率——这和"高层=深层"的说法是一致的，但视觉上容易搞反。

------

### **一句话总结**

> **浅层 = 低层特征 = 高分辨率层**（靠近输入，细节多，语义弱）
> **深层 = 高层特征 = 低分辨率层**（远离输入，语义强，细节少）

在 FPN / PANet 的语境里：

- "把高层语义传到低层" = "把深层特征传回浅层" = "把低分辨率特征上采样到高分辨率层"
- "把低层细节传到高层" = "把浅层特征送向深层" = "把高分辨率特征下采样到低分辨率层"

##  PANet
---

PANet 可以理解为 **FPN (**Feature Pyramid Networks**)的加强版**：它在“自顶向下”的语义传递之外，又补了一条“自底向上”的路径，让高分辨率细节和高层语义能双向流动。

### **PANet 主要由四部分构成**

| 模块                            | 作用                         | 说明                                                         |
| :------------------------------ | :--------------------------- | :----------------------------------------------------------- |
| **Backbone**                    | 提取多尺度特征               | 如 ResNet，输出 C2–C5 等不同层级特征图                       |
| **FPN 自顶向下路径**            | 把高层语义传给低层           | 高层特征<mark>**上采样**</mark>后与浅层特征融合，得到 P2–P5  |
| **自底向上路径聚合 PAM**        | 把低层细节传回高层           | 从 P2 开始，用 stride=2 的 3×3 卷积下采样，再与 P3、P4、P5 融合，得到 N2–N5; 数字越小，越底层。 |
| **自适应特征池化 + 全连接融合** | 让每个 proposal 使用多层特征 | 不再只依赖单一层级特征；分割分支还加入 FCN + 全连接融合      |

其中，**自底向上路径**是 PANet 最重要的改进。

FPN 只有自上而下的路径，深层语义容易传到浅层，但浅层的精确定位信息很难高效回到高层。

PANet 从 P2 出发，经过很少的层数就能把低层定位信息送到高层，所以小目标、遮挡目标的定位会更稳。

### **特征图的高分辨率 / 低分辨率

这里的“分辨率”不是图片看起来有多大，而是特征图的空间尺寸 **H × W** 有多少个位置。

假设输入是 640×640：

| 特征图             | 尺寸示例         | 含义                                 |
| :----------------- | :--------------- | :----------------------------------- |
| **高分辨率特征图** | 160×160、320×320 | 网格多，保留更多边缘、纹理、位置细节 |
| **低分辨率特征图** | 20×20、10×10     | 网格少，但语义更强，更知道“这是什么” |

更直观地说：

- **高分辨率特征图**：格子细，适合定位。比如小目标只占几个像素，必须在高分辨率层才能看清。
- **低分辨率特征图**：格子粗，但每个格子看到的原图区域更大，也就是**感受野更大**，更适合判断类别和整体结构。

所以 PANet 的思路就是：
**用 FPN 把高层语义送到低层，再用自底向上路径把低层高分辨率定位信息送回高层，让每一层都同时有“看得清”和“看得懂”的能力。**

## FPN vs PANet vs BiFPN
---

**FPN 是基础版，PANet 是双向加强版，BiFPN 是加权高效双向版。**

| 结构      | 信息流              | 核心改进                         | 典型位置                        |
| :-------- | :------------------ | :------------------------------- | :------------------------------ |
| **FPN**   | 自顶向下            | 把高层语义传到浅层               | Faster R-CNN、RetinaNet、YOLOv3 |
| **PANet** | 自顶向下 + 自底向上 | 补一条从低层回传定位信息的路径   | YOLOv4、YOLOv5、Mask R-CNN      |
| **BiFPN** | 重复双向 + 加权融合 | 用可学习权重决定每个尺度贡献多大 | EfficientDet、YOLOv5/v8 改进版  |

### **FPN：只有一条自顶向下路径**

FPN 先让 Backbone 提取 C2–C5 等多尺度特征，然后从最高层开始**上采样**，把高层语义传到低层，再通过横向连接与同层浅层特征融合，得到 P2–P5。

它的优点是结构简单、成本低；缺点是**低层细节很难高效回到高层**，小目标和遮挡目标容易丢失定位信息。

### **PANet：在 FPN 后加一条自底向上路径**

PANet 保留了 FPN 的自顶向下路径，又增加了一条**自底向上路径**：

从 P2 开始，用 stride=2 的 3×3 卷积下采样，再与 P3、P4、P5 逐层融合，得到 N2–N5。

这样低层高分辨率细节可以很快传到高层，高层特征也获得了更强的定位能力。

PANet 还提出了**自适应特征池化**，让每个 proposal 不再只依赖单一层级特征，而是同时利用多层特征。

### **BiFPN：双向路径 + 可学习权重 + 重复堆叠**

BiFPN 在 PANet 的基础上做了三件事：

1. **简化节点**：删除只有一个输入边的节点，因为这种节点没有真正融合多尺度特征。
2. **增加跨层连接**：在同一层的原始输入和输出之间加一条额外边，让信息流动更密集。
3. **加权特征融合**：不再简单相加或拼接，而是给每个输入特征分配可学习权重，再用快速归一化融合：

此外，BiFPN 会把整个双向模块**重复堆叠多次**，让多尺度特征经过多轮循环增强。

### **一句话选型**

- **FPN**：最基础，适合先理解特征金字塔。
- **PANet**：加强低层定位信息，小目标检测更稳。
- **BiFPN**：不仅双向流动，还能自适应学习每个尺度的重要性，精度和效率平衡更好。

若从工程角度看，FPN 解决“有没有多尺度特征”，PANet 解决“低层细节能不能传回去”，BiFPN 解决“不同尺度特征到底该听谁的”。

## 扩展-Yolov4网络结构

---

在 YOLOv4 里，**CSPDarknet53 是主干网络，SPP 和 PANet 都属于颈部网络**。

**CSPDarknet53 输出多尺度特征 → SPP 先增强最深层特征 → PANet 再把这些特征与浅层特征双向融合 → 最后输出 3 个尺度特征图给检测头。**

### **数据流可以按这条链路看**

以输入 416×416 为例，CSPDarknet53 会经过多次下采样，输出三个关键特征层：

- **feat1：76×76**，浅层、高分辨率，细节多，适合小目标；
- **feat2：38×38**，中层特征；
- **feat3：13×13**，深层、低分辨率，语义最强，适合大目标。

### **SPP 模块接在最深层特征上**

SPP 只作用于 CSPDarknet53 的最后一层特征 **feat3（13×13）**。

它对 feat3 分别做不同尺度的最大池化，例如 1×1、5×5、9×9、13×13，然后把池化结果和原始 feat3 在通道维度 **Concat**，再经过 1×1 卷积压缩通道。

这一步的作用是：**扩大感受野、增强全局上下文信息**，但特征图空间尺寸仍保持 13×13。

### **PANet 负责把三层特征双向融合**

SPP 输出后，PANet 开始工作，它包含两条路径：

#### **1. 自顶向下路径：把深层语义传给浅层**

- SPP 处理后的 13×13 特征先上采样到 38×38；
- 与 CSPDarknet53 的 **feat2（38×38）** Concat 融合；
- 再上采样到 76×76；
- 与 CSPDarknet53 的 **feat1（76×76）** Concat 融合。

这一步让浅层特征获得深层语义，有利于更准确地判断“是什么”。

#### **2. 自底向上路径：把浅层细节传回深层**

- 从融合后的 76×76 特征开始下采样到 38×38；
- 与前面的 38×38 特征 Concat 融合；
- 再下采样到 13×13；
- 与 SPP 处理后的 13×13 特征 Concat 融合。

这一步让深层特征重新获得浅层的位置和细节信息，有利于更准确地判断“在哪里”。

### **最后输出三个检测尺度**

PANet 融合结束后，会输出三组特征图：

- **76×76**：检测小目标；
- **38×38**：检测中等目标；
- **13×13**：检测大目标。

这三组特征再分别送入 YOLOv3 风格的检测头，预测边界框、置信度和类别。

### **一句话概括**

**CSPDarknet53 负责“提取多尺度特征”，SPP 负责“增强最深层特征的感受野”，PANet 负责“把深层语义和浅层细节双向融合”，最终形成三个尺度的特征图供检测头使用。**
