## Yolov6 SIoU 边界框回归损失函数

---

**SIoU 是在 CIoU(Complete IoU 完整IoU) 基础上额外引入“角度损失”的边界框回归损失函数，核心差异是 SIoU 会先引导预测框沿 X/Y 轴方向对齐，再优化距离和形状，因此收敛更快、对小目标更友好；**

**而 CIoU 只优化重叠度、中心距离和宽高比，不建模方向。**

### **SIoU概念**

SIoU 全称 **Scylla IoU**，是一种目标检测边界框回归损失。 

CIoU、DIoU(Distance-IoU)等只考虑重叠面积、中心点距离和宽高比，但没有考虑预测框与真实框之间的**方向关系**，训练初期预测框容易在真实框附近“游荡”，收敛较慢。

SIoU 把损失拆成四部分：

| 组件                       | 作用                                                         |
| :------------------------- | :----------------------------------------------------------- |
| **Angle Cost 角度损失**    | 计算预测框与真实框中心连线相对于坐标轴的角度，引导模型先沿 X 或 Y 轴方向移动 |
| **Distance Cost 距离损失** | 在角度约束下重新计算中心点距离惩罚，角度偏差越大，距离惩罚越重 |
| **Shape Cost 形状损失**    | 约束预测框与真实框的宽高差异                                 |
| **IoU Cost 重叠损失**      | 保留传统 IoU 对重叠区域的监督                                |

### **和 CIoU 的主要差异**

| 维度         | CIoU                       | SIoU                     |
| :----------- | :------------------------- | :----------------------- |
| 核心因素     | IoU + 中心距离 + 宽高比    | IoU + 角度 + 距离 + 形状 |
| 是否建模方向 | 否                         | 是，引入角度损失         |
| 训练行为     | 可能先在 X、Y 方向来回调整 | 先对齐坐标轴，再精细回归 |
| 收敛速度     | 相对慢                     | 通常更快                 |
| 小目标收益   | 有提升                     | 提升更明显               |
| 推理成本     | 无额外开销                 | 无额外开销，只影响训练   |

### **为什么 YOLOv6 会采用它**

YOLOv6 采用 SIoU，是因为它只改变训练阶段的监督信号，不增加推理计算量，同时能加快收敛、提升定位精度，尤其对小目标、密集目标效果更好。 

不过工程上也不是越新越好：通用场景 CIoU 已经很稳；若小目标多、收敛慢，再换 SIoU 更划算。
