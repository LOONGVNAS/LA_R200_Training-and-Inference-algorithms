## IoU 交并比计算

---

在目标检测任务中，**交并比（IoU，Intersection over Union）** 是评估模型预测框（Bounding Box）与真实标签框（Ground Truth Box）重叠程度的核心指标。

这里假设在图片中看到了两个矩形框：

- **红框（Ground Truth, GT）**：人工标注的真实物体位置。
- **蓝框（Prediction, Pred）**：AI模型预测出的物体位置。

IoU 的计算过程就是通过公式，量化这两个框的“吻合度”。

------

### **1. 核心计算公式**

IoU=交集面积 (Intersection) / 并集面积 (Union)

其取值范围在 **0 到 1** 之间：

- **IoU = 0**：两个框完全不重合。
- **IoU = 1**：两个框完全重合。
- **IoU > 阈值（如0.5）**：通常认为模型成功检测到了目标。

------

### **2. 结合图示的计算步骤拆解**

为了计算 IoU，将复杂的视觉面积拆解为简单的**坐标运算**。

假设红框坐标为 A(x1,y1,x2,y2)，蓝框坐标为 B(X1,Y1,X2,Y2)。

#### **第一步：找出“交集”区域（两个框重叠的部分）**

在图片中，交集通常是重叠最深的那个“小矩形”。我们需要确定它的左上角和右下角坐标：

- 交集左上角坐标：
  - xleft=max⁡(x1,X1)（取两者最靠右的左边）
  - ytop=max⁡(y1,Y1) （取两者最靠下的上边）
- 交集右下角坐标：
  - xright=min⁡(x2,X2) （取两者最靠左的右边）
  - ybottom=min⁡(y2,Y2)（取两者最靠上的下边）

> **注意**：若 xleft ≥ xright 或 ytop ≥ ybottom，说明两个框没有交集，此时**交集面积为 0**。

- **交集面积计算公式**：

Areaintersection=max⁡(0,xright−xleft) × max⁡(0,ybottom−ytop)

#### **第二步：计算“并集”区域（两个框合并的总面积）**

并集面积不是简单地将两个框的面积相加，因为中间重叠的部分会被重复计算。

- **并集面积计算公式**：

Areaunion=AreaA+AreaB−Areaintersection

*(即：红框面积 + 蓝框面积 - 交集面积)*

#### **第三步：得出 IoU**

将前两步的结果代入核心公式：

IoU=Areaintersection / Areaunion

------

### **3. 为什么 IoU 能衡量检测质量？**

在目标检测的图片中，IoU 直接反映了定位的精准度：

1. **防漏检（高 Recall 需求）**：若 IoU 很低（如 0.2），说明模型虽然知道这里可能有东西，但框的位置差得很远。
2. **防误检（高 Precision 需求）**：若 IoU 为 0，说明模型框了一个完全不存在的区域，或者完全没有识别到真实物体。

------

### **4. Python 代码实现（方便对照理解）**

若你正在做开发，下面是最标准的 Python 实现逻辑：

```python
def calculate_iou(boxA, boxB):
    """
    计算两个边界框的IoU
    boxA, boxB: [x1, y1, x2, y2] (左上角坐标, 右下角坐标)
    """
    # 1. 计算交集的坐标
    xA = max(boxA[0], boxB[0])
    yA = max(boxA[1], boxB[1])
    xB = min(boxA[2], boxB[2])
    yB = min(boxA[3], boxB[3])
    
    # 2. 计算交集面积 (若没有交集，面积则为0)
    inter_area = max(0, xB - xA + 1) * max(0, yB - yA + 1)
    
    # 3. 计算各自的面积
    boxA_area = (boxA[2] - boxA[0] + 1) * (boxA[3] - boxA[1] + 1)
    boxB_area = (boxB[2] - boxB[0] + 1) * (boxB[3] - boxB[1] + 1)
    
    # 4. 计算IoU
    iou = inter_area / float(boxA_area + boxB_area - inter_area)
    
    return iou
```
