## 激活函数 vs 损失函数

----

激活函数和损失函数虽然都叫“函数”，但在神经网络里的分工完全不同：

**激活函数决定每一层怎么传递特征，损失函数决定整个模型离目标还有多远。**

### **1. 本质区别**

| 维度     | 激活函数                   | 损失函数                   |
| :------- | :------------------------- | :------------------------- |
| 位置     | 隐藏层、输出层内部         | 网络最末端                 |
| 作用     | 引入非线性，控制神经元输出 | 衡量预测与真实标签的差距   |
| 输入     | 单层的线性输出             | 模型预测值 + 真实标签      |
| 目标     | 让网络能表达复杂模式       | 让模型参数朝着更准方向更新 |
| 训练角色 | 前向传播中的“计算零件”     | 反向传播的“优化起点”       |

简单理解：**激活函数是神经元的“开关”，损失函数是模型的“评分表”。**

### **2. 激活函数：让网络有非线性能力**

若没有激活函数，多层网络堆叠起来仍然等价于一个线性变换，无法学习复杂模式。

| 激活函数         | 特点                                                         | 适用位置                       |
| :--------------- | :----------------------------------------------------------- | :----------------------------- |
| **ReLU**         | 计算简单，正区间梯度为1，缓解梯度消失；但可能出现“死亡神经元” | 隐藏层首选                     |
| **Leaky ReLU**   | 负区间保留小梯度，缓解死亡 ReLU                              | 深层网络、可能出现大量负激活时 |
| **Sigmoid**      | 输出压缩到 (0,1)，适合表示概率；但容易梯度消失               | 二分类输出层                   |
| **Tanh**         | 输出压缩到 (-1,1)，零中心化更好；仍有梯度消失                | 早期 RNN/LSTM 隐藏层           |
| **Softmax**      | 将输出归一化为概率分布，所有类别概率之和为1                  | 多分类输出层                   |
| **GELU / Swish** | 平滑非线性，适合 Transformer、大模型                         | 现代 Transformer 隐藏层        |

一个常用经验是：**隐藏层优先用 ReLU / GELU；输出层按任务选择 Sigmoid、Softmax 或线性输出。**

### **3. 损失函数：告诉模型哪里错了**

损失函数把“预测有多差”变成一个可优化的数值，反向传播就是沿着它的梯度更新权重。

| 损失函数                | 适用任务            | 特点                                                 |
| :---------------------- | :------------------ | :--------------------------------------------------- |
| **MSE**                 | 回归                | 对大误差惩罚更重，对异常值敏感                       |
| **MAE**                 | 回归                | 对异常值更鲁棒，但收敛可能较慢                       |
| **Huber Loss**          | 回归                | 结合 MSE 与 MAE，兼顾鲁棒性和稳定性                  |
| **BCE / BCEWithLogits** | 二分类、多标签分类  | 衡量预测概率与真实标签差异                           |
| **CrossEntropyLoss**    | 多分类              | PyTorch 中通常自带 Softmax，输出层不要重复加 Softmax |
| **Focal Loss**          | 类别不平衡检测/分类 | 降低易分样本权重，强化难样本学习                     |
| **Dice / IoU Loss**     | 分割、检测          | 直接优化区域重叠度                                   |

### **4. 关键配对：输出层激活 + 损失函数必须匹配**

这是最容易踩坑的地方。

**隐藏层激活函数通常不直接绑定损失函数，但输出层激活和损失函数必须<mark>严格配对。</mark>**

| 任务              | 输出层激活     | 损失函数                                        |
| :---------------- | :------------- | :---------------------------------------------- |
| 回归（任意实数）  | 无 / Linear    | MSE / MAE / Huber                               |
| 回归（输出 ≥ 0）  | ReLU           | MSE                                             |
| 二分类            | Sigmoid        | BCE / BCEWithLogits                             |
| 多分类（互斥）    | Softmax        | CrossEntropyLoss                                |
| 多标签分类        | 逐标签 Sigmoid | BCEWithLogits                                   |
| Transformer / LLM | 视任务而定     | 分类用 CrossEntropy，生成常用 Logits + 对应损失 |

几个实践要点：

- **PyTorch 的 `CrossEntropyLoss` 已经内置 Softmax**，所以输出层直接给 logits 即可，不要手动加 Softmax。
- **`BCEWithLogitsLoss` 内置 Sigmoid + BCE**，数值稳定性更好。
- **隐藏层尽量别用 Sigmoid / Tanh**，深层网络中容易导致梯度消失。
- **优化器负责更新参数，损失函数负责给出优化目标**；默认任务常用 Adam，大模型训练更常用 AdamW。

### **5. 一句话总结**

**激活函数负责让网络“会思考”，损失函数负责告诉网络“哪里想错了”；**

**隐藏层多用 ReLU/GELU，输出层按任务选 Sigmoid/Softmax/Linear，再配上对应的交叉熵或 MSE 类损失。**

常见任务激活函数与损失函数配置速查表:

- 图像分类：二分类、多分类、多标签分类、概率校准

- 目标检测：YOLO系列、Faster R-CNN、RetinaNet、DETR

- 语义分割：标准像素分类、类别不平衡、多标签分割、医学图像

- 实例分割：Mask R-CNN、YOLOv8/v11-seg、全景分割

- 姿态估计/关键点检测：热力图法、回归法、多人场景

- 图像超分辨率：像素级重建、感知质量优化、视频超分

- 生成模型：GAN、VAE、扩散模型、自回归模型(LLM)

- 目标跟踪：分类头、回归头、Siamese跟踪
